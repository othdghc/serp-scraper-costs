## 什么是 SERP scraper API，为什么它在 2026 年变得难以抉择？

SERP scraper API 是一个服务，你向它发送搜索查询，它返回 Google（或 Bing 及其他引擎）的结果——有机排名、广告、“People Also Ask”（大家还在问）框、新闻、职位列表——以结构化 JSON 格式返回，而无需你自己管理代理轮换、浏览器指纹或验证码。

由于 Google 会根据搜索者的位置定制搜索结果，认真的用户需要地理定位（geotargeting）：当你追踪在德国的排名时，从德国的 IP 进行抓取，才能“像本地人一样”看到 SERP。

过去一两年里，选择变得更加复杂，原因有三个，一个可靠的对比表格应该会提到这些：

- **第一方选项已关闭或已停用。** 微软于 2025 年 8 月 11 日停用了独立的 Bing Search API，而 Google 的 Custom Search JSON API 已对新客户关闭，现有客户需在 2027 年 1 月 1 日之前迁移。对于小规模需求来说曾经便宜且简单的选项正在消失，市场也随之发生了重新洗牌。
- **定价模式差异很大。** 有些服务商按请求量收取固定费用（每次 1,000 次请求约 0.80 美元至 1.50 美元），有些则销售点数包，而那些在你使用的通用抓取 API 基础上添加了 SERP 端点的服务商——比如 ScraperAPI——则是根据目标的抓取难度来对每个页面进行定价。
- **人工智能用例创造了第二类受众。** 如果你是在为 AI Agent 提供搜索上下文数据，而不是自己解析结果页面，那么专用搜索 API 是一个不同的类别。本文重点介绍第一个用例：获取真实的 SERP 数据。

## 关于点数的真实成本：定价页面上未显示的内容

这是大多数排名文章都没有计算过的部分，然而它决定了你的账单。

ScraperAPI 按目标网站的难度对页面进行收费。标准页面消耗 1 点数。Amazon 收费 5。**Google 和 Bing 收费 25**——包括它们的子域名。LinkedIn 收费 30。此外，每当 API 必须绕过像 Cloudflare、Datadome 或 PerimeterX 这样的机器人防护时，每请求还会增加 10 点数。因此，这里的“5,000 次请求”与另一个服务商的“5,000 次请求”意味着非常不同的事情。

这是针对 Hobby 方案中 SERP 工作的月度数学计算，按公布费率计算：

- **Hobby, $49 / 100,000 点数：** 100,000 ÷ 25 = **4,000 次 Google 请求/月**，约每次 1,000 次请求花费 $12.25
- **Startup, $149 / 1M 点数：** 40,000 次 Google 请求/月，约 $3.73/1k
- **Business, $299 / 3M 点数：** 120,000 次 Google 请求/月，约 $2.49/1k
- **Scaling, $475 / 5M 点数：** 200,000 次 Google 请求/月，约 $2.38/1k
- **Professional, $975 / 10.5M 点数：** 420,000 次 Google 请求/月，约 $2.32/1k

同样的计算也解释了第三方评测中的一个反复出现的警告：标题中提到的“每次成功抓取的成本可能是该标称数字的 20 到 30 倍”。如果在使用 `render=true` 以及高级或超高级池的情况下抓取一个受保护的电商目标，100 万点数可能只能覆盖 4 万到 10 万个实际页面，而不是 100 万个。对于主要通过 Google SERP 请求（固定 25 点数）生活的 SERP 用户来说，可变性较小——但如果你将关键词追踪与产品页面的 JS 渲染结合使用，请根据实际的单页成本进行预算，而不是根据价格页面上的点数计数。

有两个仪表盘功能使得这种计算更易于管理，在对比文章中很少提及：

- **max_cost** 参数可以为单个请求设置硬性的点数上限，因此不会出现意外的昂贵抓取消耗掉你当月一半点数的情况。

## 谁应该使用 ScraperAPI 的 SERP 功能——以及谁不应该使用

最适合使用它的人群：需要每月抓取 2 万到 20 万页（主要是标准搜索和电商目标）的独立开发者和小团队，用于关键词排名追踪、价格监控或线索挖掘（lead-gen）爬虫，并且不想自己构建和轮换代理池。在不在重型机器人防护之下的目标上，默认池可以清除大多数请求，无需昂贵的高级层级。

不太适合的人群：

- **针对困难目标进行高流量抓取的用户**（LinkedIn、Instagram、重度防护的电商网站）。超高级点数乘数使得这种方式比按带宽计费的专用住宅代理计划更昂贵。
- **任何需要一小时以上会话持久性的用户**——广告验证、长期账户工作流。专用住宅或移动代理服务商更适合这种模式。
- **需要精细控制的人。** 没有用于挑选单个 IP 或 ASN 的面板。你是在购买结果，而不是基础设施。
- **需要从第一天起就获得全天候支持的小型方案买家。** Hobby 和 Startup 仅通过电子邮件/工单获得支持——没有实时聊天，没有电话。专用团队和 Slack 支持在账单上，但对每个方案都开放，这有利于大额支出客户。

关于点数耗尽的行为：默认情况下，抓取会暂停，直到你的点数续订。如果你想避免中断，Hobby 到 Professional 方案提供选择性加入（opt-in）的自动升级（当你的点数用完时自动移动到下一个方案），而 Scaling 及以上方案增加了按量付费（pay-as-you-go），以固定的每点数费率继续使用，直至达到你设置的每月上限。
